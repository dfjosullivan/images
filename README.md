
Save (one archive, multiple images)                                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                    
docker save rhino/backend:3.07.01 rhino/worker:3.07.01 rhino/frontend:3.04.22 -o rhino-3.07.01-images.tar                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                    
Put all the images in one docker save command — backend and worker share almost all their layers (both 1.72GB, same base), so a combined tar stores the shared layers once instead of twice. Saving them separately would roughly double the archive.                                                             
                                                                                                                                                                                                                                                                                                                    
Then compress — the tar is uncompressed layer data and shrinks a lot:                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                    
# Fastest on Windows if you have 7-Zip:                                                                                                                                                                                                                                                                           
7z a rhino-3.07.01-images.tar.gz rhino-3.07.01-images.tar                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                    
# Or built-in (slower, still fine):                                                                                                                                                                                                                                                                               
Compress-Archive rhino-3.07.01-images.tar rhino-3.07.01-images.zip

1. Unzip + load on the receiving machine                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                    
# If gzipped with 7z / gzip:                                                                                                                                                                                                                                                                                      
gunzip rhino-3.07.01-images.tar.gz          # → rhino-3.07.01-images.tar                                                                                                                                                                                                                                          
docker load -i rhino-3.07.01-images.tar                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                  
# Or one step, no intermediate file:                                                                                                                                                                                                                                                                              
gunzip -c rhino-3.07.01-images.tar.gz | docker load                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                   
On Windows PowerShell with 7-Zip:                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                    
7z x rhino-3.07.01-images.tar.gz            # → .tar                                                                                                                                                                                                                                                              
docker load -i rhino-3.07.01-images.tar                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                   
docker load restores rhino/backend:3.07.01, rhino/worker:3.07.01, rhino/frontend:3.04.22 with their original tags — verify with docker images | grep rhino.
